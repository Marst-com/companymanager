# 마루 — 사장/직원 업무 시스템
팀의 하루를 한곳에서. 포인트·상점·프로젝트·음성 회의를 하나의 사이드바로.

```
maru/
├─ frontend/        Vite + React (UI, Firestore 실시간 구독, WebRTC)
├─ backend/         Node + Express + firebase-admin (권한이 필요한 모든 쓰기)
├─ firestore.rules  보안 규칙 (쓰기는 서버 전용, 채팅·할 일·회의 신호만 클라이언트 허용)
├─ .env.example     프론트·백엔드 공용 환경변수 양식
├─ .gitignore  README.md  package.json
```

## 시작하기
1. Firebase 프로젝트 생성 → Authentication **이메일/비밀번호** 켜기 → Firestore 만들기
2. `firestore.rules` 내용을 Firestore 규칙에 붙여넣고 게시
3. `cp .env.example .env` 후 값 채우기 (서비스 계정 키 + 웹 앱 설정)
4. `npm run install:all`
5. 터미널 2개: `npm run dev:backend` / `npm run dev:frontend`
6. 사장 가입 → 설정에서 **회사 코드** 확인 → 포인트 페이지에서 직원 계정 생성 → 직원은 회사 코드 + 아이디로 로그인

## 기능
- **소개/로그인**: 소개 페이지, 사장 가입·로그인, 직원은 사장이 만든 계정으로 로그인
- **홈**: 인사, 포인트, 출석(연속 보너스), 진행 중 회의 참석, 공지, 내 팀 현황, 사장용 통계, 바로가기
- **포인트**: 사장이 개별/전체 지급·회수(사유 기록), 직원은 내역 확인, 직원 계정 생성·비번 재설정·삭제
- **상점**: 사장이 상품(이모지·설명·재고) 등록, 직원 구매, 사장이 주문 지급 처리
- **프로젝트**: 사장이 팀·팀장 구성/변경/해체, 전체 단톡·팀 톡·DM, 팀 할 일 보드, 최종 GitHub 링크 제출
- **회의**: 전체 회의(사장) / 팀 회의(팀장), 실시간 음성, 회의 채팅, 1:1 채팅, 손들기, 말하는 사람 표시, 경과 시간, 지난 회의 기록. 화면 공유는 사장 또는 사장이 지목한 1명만
- **설정**: 이름·프로필 색, 회사 코드, 회사 이름·출석 포인트, 회사 추가·전환

## 메모
- 음성/화면은 WebRTC 메시(P2P). 10명 이상이면 TURN(`VITE_TURN_*`) 권장. 화면공유는 30fps, 비트레이트는 `VITE_SHARE_KBPS`
- 비정상 종료한 참가자는 목록에 남을 수 있어요
